A collection of full-stack **MERN** (MongoDB, Express, React, Node.js) applications I've built end to end — REST API design, authentication, file uploads, payments and real-time communication.

Each project is a self-contained folder with its own `client/` and `server/`, and its own README with setup instructions.

## 🚀 Running a Project Locally

Every project follows the same two-part structure:

```bash
# 1. Clone the repo
git clone https://github.com/sachin-codes01/MERN-Projects.git
cd MERN-Projects/<project-folder>

# 2. Start the backend
cd server
npm install
# add your .env (MongoDB URI, JWT secret, API keys)
npm run dev

# 3. Start the frontend, in a second terminal
cd ../client
npm install
npm run dev
```

Check the individual project folder for the exact environment variables it expects.
